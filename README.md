# Sebastian Vaca — Engineering Portfolio

An interactive engineering portfolio built from scratch to showcase my
projects, technical experience, and work in computer engineering.

🌐 **Live Portfolio:**  
https://sebastianmercutiovaca.github.io/Sebastian-Engineering-Portfolio/

## About the Project

This portfolio was designed and developed from scratch as a personal
engineering interface rather than using a pre-built portfolio template.

The site highlights my work across embedded systems, hardware,
software development, robotics, and computer engineering.

## Features

- Interactive 3D engineering interface
- Animated 3D head with user interaction
- Responsive desktop and mobile layouts
- Project and engineering experience sections
- Technical toolkit showcase
- Custom animations and UI interactions
- Contact and professional links

## Built With

- HTML5
- CSS3
- JavaScript
- Three.js
- GLTF / 3D Models
- Git & GitHub
- GitHub Pages

## Project Structure

    Sebastian-Engineering-Portfolio/
    │
    ├── assets/        # Models, images, and project assets
    ├── index.html     # Main website structure
    ├── style.css      # Styling and responsive design
    ├── script.js      # Interactions and 3D functionality
    └── README.md

## Design

The portfolio uses a dark, engineering-focused interface with an
interactive 3D centerpiece. The goal was to create a portfolio that
feels more like an engineered application than a traditional
static resume website.
